# JavaScriptNotes

📚 JavaScript Basics – Personal Notes Series
This repository is a curated collection of my JavaScript basic concepts, structured as a personal learning journal with practical examples, use cases, and deep-dive explanations.

✅ Why I Created This
As a frontend developer, a solid understanding of JavaScript fundamentals is essential for writing clean, efficient, and bug-free code. I created this series to:

👨‍💻 Strengthen my foundational JavaScript knowledge.

🧠 Build long-term conceptual clarity, not just syntax familiarity.

📌 Document tricky behavior (like this, closures, hoisting, scope, etc.) for quick future reference.

🧪 Practice code examples that are frequently asked in interviews and real-world debugging.

📌 Topics Covered (Continuously Expanding)
var, let, const – scope & hoisting

Functions – regular vs arrow functions

this keyword – in objects, callbacks, and nested contexts

Closures & lexical environment

Callbacks, Promises, Async/Await

Array & Object Destructuring

Spread & Rest Operators

Call, Apply, Bind

Event Loop, setTimeout, microtasks

...and more

🎯 Benefits
Acts as a personal reference guide before interviews or project debugging

Helps others (peers, juniors, etc.) who are learning JavaScript

Reinforces concept-first learning through well-commented examples

Keeps me consistent and accountable in my learning journey
